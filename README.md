# 🎙️ Audio Multi-Language Test Suite (16k Mono)

![ASR Testing](https://img.shields.io/badge/Task-ASR--Testing-blueviolet)
![Format](https://img.shields.io/badge/Format-WAV-green)
![SampleRate](https://img.shields.io/badge/SampleRate-16kHz-orange)
![Channels](https://img.shields.io/badge/Channels-Mono-blue)

本项目是一个专门为 **ASR (自动语音识别) 模型测试** 定制的标准化音频数据集。它涵盖了 20 种语言/方言，旨在提供一个多语种环境下的基准测试集。

---

## 🌟 项目特性
* **高标准规格**：统一采用 `16,000Hz` 采样率，`16-bit` 位深，`单声道`，完全符合主流 ASR 引擎输入要求。
* **多语种覆盖**：包含从主流英语到稀有语种（如普什图语、格鲁吉亚语）共 18 种语言。
* **均衡性**：每种语言严格限制为 100 条样本，确保测试权重的公正性。
